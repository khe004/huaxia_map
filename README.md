# 舆图引擎

把一本书（演义或史书）做成可交互的历史地图：随时间变化的势力疆域、按年和事件推进的时间轴、事件与人物互相跳转、人物行迹，以及人物交汇图。

```
yutu/
├─ build.mjs              node build.mjs <书>  →  dist/<书>/index.html（含地形图片）
├─ engine/                与具体书无关的页面与交互
│  ├─ page.html           页面模板（{{title}} 等占位符由 build 填入）
│  ├─ app.js              地图、时间轴、面板
│  ├─ story.js            人物交汇图
│  └─ music.js            背景音（原创合成，或播放本地音频）
├─ basemaps/china/        底图包：投影、地形、现代行政区
│  ├─ basemap.json        投影参数、地形图层范围、国名标注
│  ├─ geo.json            河流、湖泊（中国内地主要水系取自 OpenStreetMap，境外及边疆由 tools/waters.js 补入）
│  ├─ units.topo.json     陆地：地级行政区拼块（全国 + 朝鲜、韩国、越南）与周边国家，同一份拓扑；今省界、国界、海岸线都由它合并得到
│  └─ terrain*.webp       与投影对齐的地形图
├─ books/
│  ├─ sanguo/book.js      《三国演义》
│  └─ _template/book.js   新书模板（极简楚汉示例，演示公元前年份与《史记》篇目）
└─ tools/                 重新生成底图与检查数据的脚本（npm i 于 tools/ 下）
```

## 新增一本书

1. 复制 `books/_template/` 为 `books/<书名>/`，改写 `book.js`。
2. `node build.mjs <书名>`。构建时会校验：事件里的人物都在人物表中、人物的势力已定义、事件年份在时间轴范围内且不为 0。
3. `node tools/palette.js <书名>` 检查同时期势力的配色是否容易混淆（ΔE < 25 标 ✗）。

## book.js 数据格式

所有字段都是普通的全局常量，按下面的名字定义。

### `BOOK` 配置

| 字段 | 说明 |
|---|---|
| `id` `title` `brand` `seal` `subtitle` | 标识、标签页标题、页头大字、印章字、副标题 |
| `basemap` | 使用的底图包，目前为 `china` |
| `range` `startYear` | 时间轴起止年、打开时停留的年份。公元前写负数，没有 0 年 |
| `approxBefore` | 可选。此年以前的年份只是约数：显示为“约前…”，不推算干支 |
| `yearStride` `axisTicks` | 可选。`yearStride: [[起年, 间隔], …]` 让时间轴分段抽稀（如史前每 40 年一格），事件、疆域变化、阶段所在的年份总会保留；`axisTicks` 指定时间轴下方标出的年份 |
| `baseFaction` | 所有种子点的初始势力 |
| `scope` | 纳入本书的现代行政区：`provinces` 整省；`partial` 省内部分地级市；`minLat` 外国按纬度截取（如 `{ 越南: 15.4 }`）。不在范围内的省区地图上始终显示“今某省” |
| `regions` | 古政区说明：`toggle` 地图开关文字、`unit` 种子点单位（郡）、`group` 分组单位（州）、`legendNote` 图例说明、`order` 交汇图中分组的上下顺序 |
| `calendar` | 纪年：`eras` 每个朝代的 `[[起始年, 年号], …]`，`spans` 每个朝代在本书中的起止年；或者直接写 `label(y)` 返回 `[{ d: 朝代, s: '某某几年' }]` |
| `source` | 出处：`type: 'chapters'`（章回，`refs` 为回数，`titles` 为回目数组 `[[上句, 下句], …]`，`unit` 默认“回”）或 `type: 'sections'`（篇目，`refs` 为篇名，`titles` 为 `{ 篇名: 说明 }`）；`heading` 为详情页小标题 |
| `tags` | 事件 `src` 字段到标签文字的映射，如 `{ 演义: '演义情节' }` |
| `peopleGroups` `otherGroup` | 人物页的阵营分组 `[[势力, 组名], …]` 及其余人物的组名 |
| `storyDefault` | 交汇图默认显示的人物 |
| `searchHint` `notes` `musicTitle` | 搜索框提示、本年面板底部说明、背景音按钮的悬停文字 |

### 地图与疆域

- `FACTIONS`：`{ 键: { color, name: t => 名称, hideLabel?: t => 布尔, mapName?: t => 地图上的短名 } }`。`BOOK.shortMapLabels: true` 时地图上自动去掉名称里括号中的说明（图例和面板仍显示全名）。
  - `realm?: 字符串 | t => 字符串`：势力的所属。配合 `BOOK.realms: { 键: '显示名', … }`（如 `{ han: '汉朝治下', pan: '起兵反叛' }`）：同一所属的势力之间只画细边界，不同所属之间画粗边界；图例和面板的势力列表按所属分组并给出小计，没有所属的归入 `BOOK.otherRealm`（默认“周边”）。`BOOK.looseRealms: ['键', …]` 中的所属只用于图例分组，彼此之间仍画粗边界（如互相攻伐的群雄）。`t` 为时间轴时刻 = 年 + (月 − 1) / 12，可据此按月改名。注意公元前为负数：前 206 年二月 = −206 + 1/12 ≈ −205.92，比较时要按这个数值写。
  - `blank: true`：该势力的地盘不着色、透出地形，用于“聚落稀少 · 文化面貌不明”之类的空白地区（可作为 `baseFaction`）。
- `BOOK.view`（可选）：若干 `[经度, 纬度]`，页面初始视野缩放到恰好容纳这些点，可以比默认画面更大（如需要看到漠北、西域的书），“复位”按钮回到这个视野。
- `SEEDS_RAW`：每行若干个 `分组|名称|经度,纬度`，用两个以上空格分隔。每个现代地级行政区归入最近的种子点，拼成古政区；分组即上一级（州）。
- `UNIT_OVERRIDES`（可选）：`{ 现代地级市名: 种子点名 }`，修正“最近”分错的情况。
- `SNAPSHOTS`：`[年, 月, [[势力, 范围], …]]`，按时间顺序累加。范围可写种子点名、`@分组`、`#势力`（该势力此刻的全部地盘）、`*`（全部），空格分隔。月份可以是小数，用于和同月事件排先后。
- `ZHOU_LABELS`：`[[名, 经度, 纬度], …]`，地图上的大区名。
- `CITIES`：`{ n: [[起始年, 名], …], ll: [经度, 纬度], m: '今地', cap: 1 }`，名字可随年份变化；第一个起始年之前不显示，名字写作 `''` 的年份起也不显示（用于废弃的都邑）。
- `PHASES`：`[[起年, 止年, 阶段名], …]`。

### 事件与人物

- `EVENTS`：`{ y, mo, t, p, m, ll, k, refs, src?, d, who }` —— 年、月、标题、古地名、今地、`[经度, 纬度]`、`war`|`pol`、出处、可选标签、简介、参与人物。数组顺序不要求按时间，引擎按年月排序。
  可选 `cal`：原书纪年（如“汉三年十月”），显示在事件详情里，替代按年号推算的文字。适用于岁首不在正月的历法——年份 `y` 与月份 `mo` 仍按公历填写，保证排序正确。
- 简介中可以用 `**…**` 标出原书引文，页面上显示为加粗下划线，悬停提示 `BOOK.quoteLabel`（如“《史记》原文”）。另一出处写作 `**左传|…**`，显示为蓝色虚下划线，悬停提示“《左传》原文”。`node tools/quotes.js <书> <原文目录> [左传=原文目录 …]` 逐条核对引文是否出现在原文中。
- `PEOPLE_RAW`：`[名, 势力, 字, 生卒, 简介]`。生卒写作 `161–223`、`?–220`、`前232–前202`。
- `books/_people.js`（`PEOPLE_COMMON`）：在多本书中出现的人物，字、生卒和简介统一写在这里，构建时覆盖各书 `PEOPLE_RAW` 中的同名人物（势力仍按各书）。简介写此人一生；其中的引文一律注明出处（`**史记|…**`、`**汉书|…**` 等），构建时与该书默认出处相同的会去掉前缀。用 `node tools/quotes.js _people <史记目录> 史记=… 左传=… 汉书=… 后汉书=… 三国志=…` 核对。《三国志》语料含裴松之注，引用裴注所引诸书时在正文中注明出处。

## 底图与地形

`basemaps/china` 覆盖约东经 94°–127°、北纬 18°–43°（外加一圈低清地形）。范围以外的书（如《西游记》）需要新建底图包：调整 `basemap.json` 的投影，并用 `tools/terrain.js` 按同一投影重新渲染地形（脚本内的投影参数需同步修改）。

- `tools/units.js`：由 DataV 地级边界、geoBoundaries 一级行政区和 Natural Earth 1:1000 万国界生成 `units.topo.json`。所有陆地一起简化，拼块外缘、省界和海岸线完全重合；周边国家之间的陆上国界不画，地形图按陆地轮廓裁切。
- `tools/waters.js`：从 Natural Earth 1:1000 万河流、湖泊和少量 OpenStreetMap 河道（鄂尔浑河、土拉河、克鲁伦河、弱水等）给 `geo.json` 补上境外及边疆水系，补入的要素带 `s:'x'`，重跑时自动替换。有飞地的地级区（如伊犁州的奎屯）在页面里会拆成几块，各自归入最近的种子点。
- `tools/terrain.js`：由 AWS Terrarium 高程瓦片渲染地形（`base` 层与 `relief` 层）。
- `tools/palette.js`：检查配色。

数据来源：DataV 行政区划、geoBoundaries、Natural Earth、OpenStreetMap（河流，ODbL）、AWS Terrarium 高程。

## 合集（连续阅读）

`series.json` 列出合集的卷目和顺序。`node build-series.mjs` 会把每卷构建到 `dist/series/<书>/index.html`，三张地形图只在 `dist/series/` 放一份，同时生成目录页 `dist/series/index.html`。

- 合集里的每卷，时间轴一栏会显示"卷几 / 共几卷"、"目录"、"‹ 上一卷"和"下一卷 ›"。读到最后一个事件，"下一卷"按钮会亮起。
- 链接带 `?at=start`（从下一卷开头读起）或 `?at=end`（回到上一卷的最后一个事件）。
- 跨卷人物：同一人物在两卷以上出现时（以人物名为准，各卷须写成同一个名字；同名异人要区分写法，如“楚怀王”与“楚怀王心”），人物页的经历事件会按时间插入其他卷的事件，标“见卷几《…》”，点击跳到那一卷，链接带 `?ev=事件标题&p=人物`，打开该事件并沿此人的行迹浏览。
- 跨卷衔接：`node tools/seam.js` 比较相邻两卷交界处（上卷最后一个事件、下卷第一个事件）各地块的势力名称，列出不一致之处。新增或修改一卷后应跑一遍，名称以外的差异都要有史实依据。
- 地图变动要落在对应的事件上：地图在“第一个时间不早于快照的事件”处显示变化，所以快照的年月应与描述这次变动的事件一致（同月有几个事件时用小数月份排先后），事件简介里要写到这次变动；没有合适事件的，补一句简介或补一个事件。`node tools/snapev.js [书 …]` 列出显示事件的简介里没有提到变动地名的快照，逐条确认，同时检查快照是否按时间排序。
- 单本构建（`node build.mjs <书>`）不受影响，不显示这些导航。
- 发布时以目录页为主页，各卷的 index.html 和地形图作为附带文件一起发布。

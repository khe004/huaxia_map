# 华夏舆图

**在线阅读：https://khe004.github.io/huaxia_map/**

一套可以交互的中国历史地图，按正史、民国文献和考古发现编成，从新石器时代一直讲到 1949 年中华民国政府迁台，共 82 卷。每卷是一段历史：疆域随时间推移而变化，时间轴按年、按事件推进，事件和人物可以互相跳转。八十二卷首尾相接，可以从头到尾连续读下去。

全书止于 1949 年。此后的历史距今太近，档案大多尚未公开，各方的说法分歧很大，许多当事人的著作也还在版权期内，难以照前面各卷的办法写出公认的叙述，因此不再续写，依“隔代修史”的惯例留给后人。

## 读法

- **地图**：古代的州郡由今天的地级行政区拼合而成，按所属势力上色，跟着时间轴一步步变化。地图上标有都城和重要城邑，名称随年代改换；地形、今省界、古州名和城邑都可以单独开关。
- **时间轴**：一步就是一个事件，可以逐个翻，也可以自动播放；右侧有本年概况、大事记和人物表。每个事件写明原书的纪年，几个政权并立时一并列出各家年号（如“绍兴十一年 · 金皇统元年”），还注明出处篇目，并附有原文引文。
- **人物**：每卷有人物表，按阵营分组，每人写字号、生卒和一生的简介。点开人物，地图上会画出此人的行迹，并列出其经历的事件。跨卷的人物合为一人，别卷的经历按时间插入，点击可以跳过去。
- **人物交汇图**：几个人一生中在哪些事件上相遇，横着排在同一条时间线上。
- **目录页**：分“卷目”“人物”“事件”“检索”四栏。检索可以按人名、字号、古今地名、年号或事件来查，跨全部各卷。
- **卷与卷**：读完一卷，“下一卷”从下一卷开头接着读。相邻两卷有时时间重叠、各讲一条线索（如春秋的齐桓公与晋献公），时间轴上会标出重叠的年份。

## 依据

- **史书**：《史记》《左传》《汉书》《后汉书》《三国志》《晋书》《宋书》《南齐书》《梁书》《陈书》《魏书》《北齐书》《周书》《北史》《隋书》《旧唐书》《旧五代史》《新五代史》《资治通鉴》《续资治通鉴长编》《建炎以来系年要录》《宋史》《辽史》《金史》《元史》《明史》《清史稿》。上古一卷兼用考古发现。民国没有正史，正文按通行史书写，引文只取维基文库所收、已进入公有领域的当时文献：公文、条约、宣言、电文与时人记述（如杜亚泉《帝制运动始末记》、袁克文《辛丙秘苑》）。
- **引文**：事件和人物简介中加粗、带下划线的文字是原书原文。引文都用脚本与原书原文逐条核对过。
- **年月**：年份、月份一律换算成公历，所以排序前后一致；原书的纪年另外写在事件详情里。
- **疆域**：画的是各势力实际控制的范围，以州郡为单位，是示意，不是精确的边界。底图以外的周边地区多半不上色；清代后期把俄国、日本的本土也画了出来。

地图数据：DataV 行政区划、geoBoundaries、Natural Earth、OpenStreetMap（河流，ODbL）、AWS Terrarium 高程。

## 自己构建

只需要 Node.js，不装依赖：

```sh
node build-series.mjs        # 生成 dist/series/，用浏览器打开 dist/series/index.html
```

推送到 `main` 后，GitHub Actions 会自动构建并发布到上面的网址（`.github/workflows/pages.yml`）。

引擎本身、`book.js` 的数据格式和各种检查脚本，见 [ENGINE.md](ENGINE.md)；后续的计划和调试记录见 [ROADMAP.md](ROADMAP.md)。
